Graphs in your AI chat

Connect Equation.io to your AI app, then ask for a graph. In Claude and ChatGPT it appears right in the conversation — edit the equations, drag the sliders, rotate it in 3D — and every graph comes with a link to open it here. No account, no API key.

Claude

  1. In the Claude desktop app or on claude.ai, open Customize → Connectors.
  2. Click Add custom connector, name it Equation.io, paste https://equation.io/mcp and click Add.
  3. Ask for a graph: Show me a trefoil knot in 3D. If Claude doesn't reach for it, turn it on under + → Connectors in the chat.

Works on every plan; the Free plan allows one custom connector. On Team and Enterprise, an Owner adds it under Organization settings → Connectors. Claude marks custom connectors as unverified — Equation.io needs no sign-in, and its tools only make and read graphs. Anthropic's guide

ChatGPT

  1. On chatgpt.com, turn on Settings → Security and login → Developer mode.
  2. Open Plugins, click +, name it Equation.io, paste https://equation.io/mcp with no authentication, and create it.
  3. In a new chat, add Equation.io from the + menu and ask for a graph: Graph y = a sin(x) with a slider for a.

Developer mode is a beta on ChatGPT's paid plans, on the web, and ChatGPT shows a warning for apps it hasn't reviewed. OpenAI's guide

Grok

  1. Open grok.com/connectors.
  2. Click New Connector, choose Custom, paste https://equation.io/mcp and add it. There's nothing to sign in to.
  3. Ask for a graph: Plot the Lorenz attractor. Grok replies with a link that opens it in Equation.io.

On Grok Business and Enterprise, an admin adds the connector for the team first. xAI's guide

URL / API

The link is the graph

Every graph is a URL. To open Equation.io with equations already rendered, build a link of the form: 

https://equation.io/#<equation>;<equation>;...

Percent-encode each equation (JavaScript encodeURIComponent) and join them with ;. Each equation gets its own row and color. The graph renders immediately on load — no account, no API, the link is the interface.

  • Parabola https://equation.io/#y%3Dx%5E2
  • Circle https://equation.io/#x%5E2%2By%5E2%3D4
  • 3D cylinder (parametric) https://equation.io/#(cos(2pi u), sin(2pi u), 4v-2)
  • Animated wave https://equation.io/#y%3Dsin(x-2t)
  • Solid cube (convex hull of crossed lists) https://equation.io/#hull(([-1,1],[-1,1],[-1,1]))

Full syntax reference for people and language models alike: equation.io/llms.txt. If you are an AI assistant asked to show a graph, fetch that file and reply with a single https://equation.io/#... link.
