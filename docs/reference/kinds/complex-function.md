A complex function of w = x + iy, shown on the plane as field lines and
equipotentials.

## Examples

- Dipole: `ln(w-2) - ln(w+2)`
- Joukowski map: `w + 4/w`

## Pitfalls

- `domain(…)` and `conformal(…)` show the same function as a
  [domain colouring](#domain2d) or a [conformal map](#conformal2d).
