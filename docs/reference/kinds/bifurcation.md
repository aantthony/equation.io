A bifurcation (orbit) diagram: a recurrence whose step uses x as its
parameter, drawn as where its orbit settles for each x.

## Examples

- Logistic map: `a_{n+1} = x a_n (1 - a_n)`

## Pitfalls

- A recurrence using x as a bifurcation parameter cannot also supply
  constant terms without binding that parameter (see [Sequence](#sequence)).
